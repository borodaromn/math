Алгоритм пошуку дільників числа, за таблицею простих чисел

Покрокове дослідження розкладу числа на прості множники та обчислення кількості його натуральних дільників.

Що обчислює програма

Не перебираємо всі числа-кандидати на дільники

Алгоритм розкладає число на прості множники, а потім за цим розкладом обчислює кількість натуральних дільників. Для цього достатньо перевіряти прості числа з уже підготовленої таблиці.

n = p₁a₁ · p₂a₂ · … · pₘaₘ

Тут p₁, p₂, …, pₘ — різні прості множники, а a₁, a₂, …, aₘ — кількість входжень кожного простого множника.

Правило 1. Основна теорема арифметики

Будь-яке натуральне число, більше за 1, можна подати як добуток простих чисел. Такий розклад єдиний, якщо не враховувати порядок множників.
Приклад60 = 2 · 2 · 3 · 5 = 2² · 3 · 5
Складені множники окремо шукати не потрібно: наприклад, 4 = 2 · 2, 6 = 2 · 3, 9 = 3 · 3. Їх уже враховують прості множники.

Правило 2. Формула кількості дільників

Якщо розклад числа має вигляд, наведений вище, то кількість його натуральних дільників дорівнює:
D(n) = (a₁ + 1)(a₂ + 1)…(aₘ + 1)
Приклад для 6060 = 2² · 3¹ · 5¹, тому D(60) = (2+1)(1+1)(1+1) = 12.

Правило 3. Чому множимо на k + 1

Якщо простий множник p входить у розклад k разів, то в дільнику його можна використати в степені від 0 до k.
Наприклад, p²Можливі варіанти: p⁰ = 1, p¹ = p, p². Маємо три варіанти, тобто k + 1 = 3.
Для різних простих множників ці варіанти комбінуються незалежно, тому кількості перемножуються.

Правило 4. Перевіряємо тільки прості числа

Достатньо послідовно ділити число на прості числа з таблиці: 2, 3, 5, 7, 11, 13, … Якщо просте число не ділить залишок, переходимо до наступного.
Навіщо це?Складене число має простий дільник. Отже, коли прості множники перевіряються послідовно, складені множники не можуть залишитися непоміченими.

Правило 5. Коли можна зупинити перевірку

Якщо для поточного залишку n виконується умова p · p > n, подальший перебір не потрібний.
ПоясненняЯкби залишок n був складеним, у нього обов'язково був би простий дільник не більший за √n. Усі такі прості числа вже перевірені.
Тому залишок, більший за 1, на цьому етапі є простим числом.

Правило 6. Що означає залишок n > 1

Після циклу може залишитися один простий множник, який зустрівся один раз. Його показник дорівнює 1, тому він додає множник (1+1) = 2 до кількості дільників.
У кодіif n > 1: res = res * 2
Якщо залишок дорівнює 1, додатковий множник не потрібний.

Особливі випадки та межі алгоритму

n = 1
Є один натуральний дільник — саме число 1. Тому результат дорівнює 1.
n = 0 або n < 0
Цей алгоритм їх не обробляє: перевіряються лише натуральні числа від 1 до max_n.

Має два дільники: 1 і саме число. У формулі це (1+1) = 2.

Таблиця простих чисел створюється один раз до max_n. Функція erato(n) використовує готовий список primes для кожного нового числа.
